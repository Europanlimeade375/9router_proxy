## 🛠️ Using the proxy tool

The software serves as a middleman between your computer and AI services. To route your traffic, follow these steps:

1. Open your AI application settings.
2. Find the section labeled Proxy or Network Settings.
3. Enter "127.0.0.1" as the server address.
4. Enter the port number provided on the 9router_proxy dashboard.
5. Save your settings and return to 9router_proxy.

The tool now captures every request your AI application makes. You can see the raw data in the request log.

## 📋 Managing your requests

The main view lists your current requests. If you click on an entry, the program reveals the details of the request. You can view the headers, the content payload, and the destination address. 

To modify a request:
1. Select the request from the list.
2. Press the edit button.
3. Change the data fields.
4. Click submit to send the updated information to the AI provider.

This process allows you to remove sensitive user data, add specific instructions, or change the request format before the AI processes the information.

## 🛡️ Privacy and security

The tool processes your data locally on your machine. No information leaves your computer unless you explicitly send it to an AI provider through the proxy. Because this software uses a local connection, your data remains within your control.

## 🔧 Resolving common issues

If the application fails to capture traffic, check your system settings:

*   Check if another program uses the same communication port. Change the port number in the settings menu if a conflict occurs.
*   Ensure your firewall allows 9router_proxy to access the internet.
*   Verify that your AI software points to the correct local address.

If you encounter errors, restart the application and check your network settings. You can often fix connection drops by toggling the proxy switch within the main dashboard.
